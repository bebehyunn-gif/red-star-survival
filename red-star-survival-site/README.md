# 붉은 별 서바이벌

러시아군 지원을 불러 좀비 떼를 막아내는 픽셀 서바이벌 게임입니다.
레벨업마다 전차·장갑차·헬기·공중지원을 소환하고, 러시아에서 시작해 세계 각지를 해방하세요.

## 플레이
- **이동:** 화면을 터치한 채 끌기 (PC는 WASD / 방향키)
- 사격은 자동, 레벨업하면 지원을 고릅니다.
- 진행 상황(훈장·스킨·해방 지역)은 브라우저에 자동 저장됩니다.

## 구성
- `index.html` — 게임 전체 (외부 파일 없이 이 파일 하나로 실행)
- `.nojekyll` — GitHub Pages가 파일을 그대로 쓰도록 하는 빈 파일

## GitHub Pages로 배포
1. 이 폴더의 파일을 새 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 플레이할 수 있습니다.
